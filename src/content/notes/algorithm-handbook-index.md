这是一份我自己整理的算法学习手册。原始笔记内容比较长，所以这里按主题拆成 6 章，方便平时复习和查模板。

## 学习路线

```text
算法
├─ 01 基础与数组区间
├─ 02 常用数据结构与搜索
├─ 03 动态规划
├─ 04 图论
├─ 05 数学、位运算与字符串
└─ 06 树与进阶数据结构
```

## 章节

1. [基础与数组区间](/notes/algorithm-handbook-01-foundations-array)
   - 复杂度、模拟、排序、前缀和、差分、双指针、二分、贪心
2. [常用数据结构与搜索](/notes/algorithm-handbook-02-data-structures-search)
   - 哈希、栈、单调结构、队列、堆、DFS、BFS、回溯
3. [动态规划](/notes/algorithm-handbook-03-dynamic-programming)
   - DP 入门、0/1 背包、完全背包、LIS、区间 DP
4. [图论](/notes/algorithm-handbook-04-graph)
   - DSU、拓扑排序、Dijkstra、Kruskal
5. [数学、位运算与字符串](/notes/algorithm-handbook-05-math-bit-string)
   - GCD、快速幂、筛法、状态压缩、KMP
6. [树与进阶数据结构](/notes/algorithm-handbook-06-tree-advanced-ds)
   - 树形 DP、Fenwick、线段树、博弈论基础

## 我怎么用这份手册

每个主题尽量保留同一种结构：

- 算法思想
- 识别信号
- C++ / Python 模板
- 常见坑点
- 例题与练习

复习时先看“识别信号”，再尝试自己写模板，最后用例题检查是否真的会用，而不是只背代码。
